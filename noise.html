What do these numbers mean?
Browsers can’t measure true SPL dB without hardware calibration. This is an estimate based on your microphone. Use Calibration to match a quiet room (~35–45 dB) and normal speaking (~55–65 dB). Relative mode shows Δ above the room baseline and is the most consistent across different mics.
Microphone blocked?
If you see MIC BLOCKED, allow microphone access:
  • Chrome/Edge: click the lock icon → Site settings → Microphone → Allow
  • Reload the page after changing permission
  • On iPad: Settings → Safari → Microphone → Allow (or per-site prompt)
